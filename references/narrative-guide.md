# 叙事版生成规范（Narrative Guide）

> 用途：生成叙事版 PCD 前必读。叙事版 = 给人读的"认知文章"，是结构版的叙述化重构（不是机械翻译）。

## 一、叙事版 8 要素（生成时必须齐全）

| # | 要素 | 要求 |
| --- | --- | --- |
| 1 | 认知标题 | 陈述式表达，直接点明核心议题，拒绝疑问式营销标题（例："人是应该选择去一线城市发展，还是选择去老家发展"）。认知标题 vs 传播标题分离：传播标题仅对外发布时另起，不进入 PCD。 |
| 2 | 副标题 | 对主标题补充说明，界定讨论范围（例："——一线城市与老家职业发展的底层逻辑"）。 |
| 3 | 派生归属行 | 标注派生自哪个结构版（主题名 + 版本号）、原始来源（source），并声明"基于真实素材/未虚构案例"；若含联网补充案例，逐条标注来源。 |
| 4 | 引子 | 用真实、有画面感的场景开场（取自结构版"思考缘起【背景】"与 `source_summary`）。 |
| 5 | 层层铺垫 | 递进式结构，每层展开一个核心概念，逐步推进到核心判断。 |
| 6 | 讲给谁听 | 叙述化呈现适用范围与边界条件（取自结构版"边界与反例"），诚实、不绝对化——是论述与解释，不是说服与煽动。 |
| 7 | 金句收束 | 一句有力、凝练的话作结尾（取自 `core_quote`）。 |
| 8 | 核心记忆卡 | 3-5 个关键词 + 串联关系 + 一句核心逻辑（见下）。 |

## 二、核心记忆卡设计

**为什么必须有**：人记文章靠关键词串联（大脑是网络不是硬盘、语义编码进入长时记忆），无法整段背诵。好文章不仅要"能看懂"，还要"能带走"。

**格式**：

```
【核心记忆卡】
关键词：
1. 关键词A：词 + 一句话解释
2. 关键词B：词 + 一句话解释
3. 关键词C：词 + 一句话解释
（3-5 个）
串联关系：这些关键词怎么连成一条线（如 A 决定起点 → B 决定速度 → C 决定上限）
核心逻辑：一句压缩整篇认知的话
```

**硬规则**：
1. 关键词必须**可复用**——在别的场景能唤起整篇认知；
2. 不用 emoji、不用营销符号——认知文档保持克制；
3. 不在每段加关键词标签——不破坏叙述性（结构化不能杀死叙述性）；记忆锚点通过小标题自然含关键词 + 结尾记忆卡实现。

## 三、写作要求

1. 连贯叙述、有具体例子、能从头通读到尾（像一篇随笔，不是要点堆砌）；
2. 有场景、有对话感、有节奏感——不是结构版的"翻译"；
3. 不虚构内容：核心案例必须来自 `source_summary`；确需补充外部案例时，明确标注"例：来自某来源"，不得编造；
4. 不写用户私密信息；涉及用户真实经历前先询问确认。

## 四、验收标准

- [ ] 8 要素齐全（含核心记忆卡）
- [ ] 整篇能像文章一样从头通读到尾
- [ ] 读者凭核心记忆卡能复述整篇论述
- [ ] 无虚构案例、无营销化标题（认知标题保持陈述式）
