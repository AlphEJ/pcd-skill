# PCD Skill · 个人认知文档（双版本）

PCD（Personal-Cognition-Document，个人认知文档，旧称 PPD）是一套把零散感悟沉淀为结构化认知资产的方法论，参考产品 PRD 的工程化思维：把脑子里的模糊想法，变成可回溯、可迭代、可关联的"思想说明书"。

## 双版本设计

- **结构版**：认知数据库（= 叙事版的 PRD）。YAML 元信息 + 10 个结构化模块，供 AI 解析、检索、网络关联与版本迭代。
- **叙事版**：认知文章。8 要素 + 核心记忆卡，供人阅读与记忆——人靠关键词串联记忆，3-5 个关键词 + 一句核心逻辑即可复述整篇论述。

结构版认知更新 → 叙事版标「待同步」→ 按变更点同步 →「已同步」。

## 核心理念

- 写前命题检验四问（逻辑自洽 / 反例 / 隐含假设 / 定性结论），不沉淀错误认知
- 写后 status 闭环（假设 / 已验证 / 已更新 / 已废止），记录认知生命周期
- related_principles 构建个人认知网络：同域必连；跨域有连接点可连；无连接点不连（宁缺毋滥）
- 连接点五类：概念共用 / 机制互释 / 场景重叠 / 结论互用 / 约束互补
- source_summary 防幻觉：叙事版只基于真实素材生成，不编造案例
- 双文件命名配对：`主题名-PCD-结构版.md` / `主题名-PCD-叙事版.md`

## 快速开始

1. 将本仓库根目录作为 Skill 文件夹，放入你的 AI Agent 技能目录（如 `workspace/.user_skills/`）
2. 对 AI 说：**"把这条视频做成 PCD" / "拆书" / "沉淀这条感悟" / "生成双版本"**
3. AI 走四步流水线：解析素材 → 提取核心观点（含命题检验）→ 生成结构版 → 生成叙事版

    └── narrative-guide.md      # 叙事版生成规范

## 隐私与边界

- 本 Skill（开源部分）不含任何个人隐私信息（姓名 / 手机号 / 邮箱 / 密码 / 账号 / token）
- PCD 文档是用户私有数据；写入用户真实经历前需先经用户确认；开源示例均为脱敏虚构
- PCD 是个人知识库自定义范式，**非行业通用标准**
